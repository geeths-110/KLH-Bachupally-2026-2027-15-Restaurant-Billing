# Week 11 — Collections Framework
## Aim
To implement Java Collections for managing restaurant menu items, customer orders, prices, and kitchen queues.
## Procedure
1. Create the FoodItem and Order classes.
2. Use ArrayList to store menu items and ordered food items.
3. Use HashMap to store food names and their prices.
4. Use TreeMap to display the price list in alphabetical order.
5. Use TreeSet to store unique menu item names in sorted order.
6. Use LinkedList as a queue to manage kitchen orders.
7. Use ArrayDeque to track the most recently added food item.
8. Use generics to specify the types of elements stored in collections.
9. Calculate the subtotal, discount, tax, and total bill.
10. Save the order report using file handling.
11. Read and display the saved report.
## Concepts Used
- ArrayList
- LinkedList
- HashMap
- TreeMap
- TreeSet
- Queue
- Deque
- ArrayDeque
- Generics
- Map.Entry
- Enhanced for loop
- File handling
## Result
The program manages restaurant orders using different collection types, calculates the final bill, and saves the report to a file.
