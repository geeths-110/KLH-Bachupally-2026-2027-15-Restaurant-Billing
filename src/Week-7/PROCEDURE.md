# Week 7 — Classes and Objects
## Title
Restaurant Order and Billing System Using Classes and Objects
## Objective
To implement classes, objects, constructors, encapsulation, static members, and composition in the restaurant billing system.
## Problem Statement
The restaurant needs to store food details, manage customer orders, calculate bills, and display kitchen status using object-oriented programming.
## Input
- Customer name
- Food choice
- Quantity
- Kitchen status
## Process
1. Create a FoodItem class with private fields for name, price, and quantity.
2. Initialize food details using a parameterized constructor.
3. Create an Order class to store customer details and food items.
4. Use an ArrayList to store multiple FoodItem objects.
5. Calculate the subtotal and total quantity through methods.
6. Calculate the discount and 5% tax.
7. Display the order, kitchen status, and final bill.
8. Use a static variable to count orders created.
## Algorithm
1. Start.
2. Read the customer name.
3. Create an Order object.
4. Display the menu.
5. Read food choice and quantity.
6. Create a FoodItem object and add it to the order.
7. Repeat until the customer finishes ordering.
8. Calculate subtotal, discount, tax, and total bill.
9. Read and display kitchen status.
10. Display order details and order count.
11. Stop.
## Concepts Used
- Classes and objects
- Constructors
- Encapsulation using private fields
- this keyword
- Getters
- toString() method
- Static members
- Composition
- ArrayList
- Methods
