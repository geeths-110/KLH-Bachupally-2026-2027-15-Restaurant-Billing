# Week 9 — Strings and Library Algorithms
## Aim
To implement String manipulation, StringBuilder, sorting, searching, Comparable, and Comparator in the restaurant billing system.
## Procedure
1. Create a FoodItem class containing the food name, price, and quantity.
2. Implement Comparable to sort food items alphabetically by name.
3. Use Arrays.sort() to arrange the menu.
4. Use Arrays.binarySearch() to search for a food item by name.
5. Use Comparator to sort ordered food items by price.
6. Use trim() to remove extra spaces from input and validate the customer name.
7. Use toUpperCase() to display the customer name in uppercase.
8. Use StringBuilder to prepare the order receipt.
9. Calculate the subtotal, discount, tax, and final bill.
10. Display the order details and kitchen status.
## Concepts Used
- String methods: trim(), toUpperCase(), compareToIgnoreCase()
- StringBuilder: append()
- Comparable and compareTo()
- Comparator and comparingDouble()
- Arrays.sort()
- Arrays.binarySearch()
- Input validation
- Exception handling
- Lambda expressions
## Result
The program sorts the restaurant menu, searches for food items, formats customer details, and generates the final bill.
